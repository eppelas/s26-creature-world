# S26 · мир существ

Страницы для телеграм-бота [@s26_tamagotchi_bot](https://t.me/s26_tamagotchi_bot).

- `/` — общий мир: все существа и кому из них нужно внимание
- `/app/` — мини-апп одного существа, открывается кнопкой из бота

## Что здесь лежит и чего здесь нет

`world.json` содержит только то, по чему нельзя узнать человека: имя существа,
вид, стадию, состояние и четыре числа, задающие вид пространства.

Ни описаний проектов, ни записей «что я сегодня сделал», ни telegram id, ни
юзернеймов здесь нет и не будет — это остаётся на машине у ведущей.

Страницы и код собираются из репозитория бота: `node scripts/build-web.mjs`.
Править файлы здесь напрямую бессмысленно, сборка их перезапишет.
